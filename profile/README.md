# LinkClipper

**Save the web you love. Find it again, in one place.**

LinkClipper is a local-first Chrome/Brave (MV3) extension that clips anything you browse — YouTube Shorts, reels, articles, pages — into boards you can tag, search, revisit.

- Website: https://linkclipper.github.io
- Extension source: https://github.com/linkclipper/linkclipper
- Privacy: https://linkclipper.github.io/privacy.html
- Privacy-first: no accounts, no analytics, data stays in your browser; optional command of your own Supabase project.
