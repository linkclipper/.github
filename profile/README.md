# LinkClipper

**Save the web you love. Find it again, in one place.**

LinkClipper is a local-first Chrome/Brave (MV3) extension that clips anything you browse — YouTube Shorts, reels, articles, pages — into boards you can tag, search, revisit. Growing toward shared, discoverable collections.

- Website: https://linkclipper.github.io
- Privacy: https://linkclipper.github.io/privacy.html
- Law of the repo: works offline, no accounts, no analytics.

## Where we are

Phase A (foundation) is done: local-first storage with optional user-owned sync, in-page saves on the big social sites, in-place reader + playback, schema migration ladder, CI, tagged releases. Next: Phase B — board share links. See the [open roadmap](https://github.com/linkclipper/linkclipper/blob/main/docs/ROADMAP.md).
